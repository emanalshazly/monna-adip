# قاموس MONNA ADIP العربي–الإنجليزي

| المصطلح الإنجليزي | المقابل العربي المستخدم | ملاحظة |
|---|---|---|
| Agent | وكيل ذكاء اصطناعي | نظام يستخدم نموذجًا وأدوات لتنفيذ أفعال. |
| Agent Data | بيانات الوكيل | البيانات المسترجعة أو المتولدة أثناء التنفيذ. |
| Agent Data Injection (ADI) | حقن بيانات الوكيل | جعل بيانات غير موثوقة تبدو كأنها بيانات موثوقة. |
| Prompt Injection | حقن التعليمات | محاولة جعل البيانات تُفسّر كتعليمات. |
| Trust Boundary | حد الثقة | الفاصل بين بيانات ذات مصادر وضمانات مختلفة. |
| Trusted | موثوق | لا يستخدم إلا مع مصدر وحماية سلامة يمكن إثباتهما. |
| Untrusted | غير موثوق | يستطيع طرف خارجي التأثير فيه. |
| Derived | مشتق | ناتج من مدخلات أخرى ويرث درجة الثقة ذات الصلة. |
| Unknown | مجهول الثقة | لا يوجد دليل كافٍ على المصدر أو السلامة. |
| Provenance | سلسلة المصدر | أصل القيمة والتحويلات التي مرت بها. |
| Provenance Check | تحقق من سلسلة المصدر | تحقق مستقل من أن القيمة جاءت من المصدر المعلن. |
| Structural Isolation | عزل بنيوي | منع اختلاط structure الموثوق بالمحتوى غير الموثوق. |
| Structural Ambiguity | التباس بنيوي | احتمال اختلاف تفسير النموذج لبنية البيانات عن النظام. |
| Security Anchor | مرتكز أمني | قيمة يعتمد عليها النظام في قرار أمني، مثل ID أو Origin. |
| Action Argument | مُدخل فعل | القيمة التي تمر إلى Tool أو API أو عملية تغيير. |
| Mitigation | إجراء حماية أو تخفيف | ضابط يمنع الخطر أو يقلله أو يكتشفه أو يساعد في التعافي. |
| Verification Evidence | دليل تحقق | Test أو Log أو Policy أو Review يثبت عمل الضابط. |
| Deterministic Validation | تحقق حتمي | فحص بقواعد أو parser لا يعتمد على تفسير النموذج. |
| Data-Flow Tracking | تتبع تدفق البيانات | الحفاظ على وسم المصدر والثقة خلال التحويلات. |
| Taint Tracking | تتبع وسم عدم الثقة | منع فقدان علامة أن البيانات متأثرة بمصدر غير موثوق. |
| Same-Context Confirmation | موافقة من نفس السياق | موافقة بشرية مبنية على عرض قد يكون متأثرًا بنفس الخطأ. |
| Review Ready | جاهز للمراجعة | لا توجد فجوة baseline عالية/حرجة؛ ليست شهادة أمان. |
| Exposed | مكشوف | يوجد مسار عالي/حرج بلا ضابط مستقل كافٍ. |
| Incomplete | غير مكتمل | معلومات المصدر أو الاعتماد المطلوبة غير متوفرة. |

## قاعدة الاستخدام

تُستخدم المصطلحات العربية في الشرح، لكن تبقى identifiers والقيم المعيارية
بالإنجليزية داخل JSON وCLI وSARIF لضمان التوافق.
