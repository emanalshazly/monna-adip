# Security Policy

## Scope

MONNA ADIP is a defensive assessment project. Reports about the Lite analyzer,
schema, or documentation are welcome.

## Do not file publicly

- Exploit payloads or working attacks against live agents
- Unpublished vendor vulnerability details
- Secrets, tokens, client records, or proprietary tool responses
- Instructions that materially enable remote code execution or supply-chain abuse

Use GitHub private vulnerability reporting before public disclosure. The
repository owner should keep that channel enabled and monitored.

## Supported versions

Only the latest tagged minor release receives security updates during the
research-extension phase.
